# ISS_Lab3_Haptics

# Description:

Operation!

In this lab, the goal is to create a system that explores haptics using a vibration motor. My goal was to create the a recreation of the game Operation using the vibration motor as the buzzer and capacitive touch, developed from lab 1, as the point that triggers the buzzing. I created a laser cut acrylic enclosure, using Rhino, with holes to hold the objects that the player retrieves with the tweezers. The holes are lined with copper tape that is all connected on the underside, and then connected to a wire that plugs into the board. The code recognized a change in the copper tape and when recognized, the vibration motor goes and the red light turns on. The goal of the game is to get all of the items out of the body without touching the tape and triggering the vibration.

# Run instructions:

The code is uploaded onto the ESP32, so to run the system you plug the wire from the enclosure into 32 on the breadboard then plug the microcontroller into a power source. The game is now ready to play
